# 첫 글을 함께 만들어 보기

[첫 화면으로 돌아가기](../README.md)

목표는 **내 네이버 블로그의 임시저장 목록에서 사진과 상담 안내가 들어간 매물 글 한 편을 확인하는 것**입니다. 아래 순서대로 진행하세요.

## 1. 설치를 확인하세요

아직 설치하지 않았다면 [README의 설치 요청문](../README.md#①-처음-한-번-설치-요청하기)을 Codex에 보내세요.

설치 후 새 대화에서 아래처럼 입력합니다.

```text
$realtor-naver-blog-browser
첫 사용입니다. 스킬 설치와 글 작성에 필요한 기능을 확인해줘.
```

스킬을 찾을 수 없다고 하면 [설치 문제 해결](troubleshooting.md)을 참고하세요.

## 2. 매물과 내 블로그를 알려주세요

네이버 매물번호가 있으면 번호를 전달하세요. 번호는 매물 상세 화면의 `매물번호` 항목에서 찾을 수 있습니다. 지도 공유 링크만으로는 매물이 특정되지 않을 수 있으므로 번호나 매물 상세 링크를 쓰는 편이 좋습니다.

**무엇을 줘도 됩니다.** 아래 세 가지 중 편한 방식으로 시작하세요.

① 매물번호

```text
$realtor-naver-blog-browser 매물번호 2645188091로 블로그 글 만들어서 임시저장까지 해줘.
```

② 매물 페이지 링크 붙여넣기

```text
$realtor-naver-blog-browser 이 매물 링크로 블로그 글 만들어서 임시저장까지 해줘. 내가 중개하는 매물이야.
https://fin.land.naver.com/articles/2645188091
```

③ 말로 설명하고 사진 폴더 주기

```text
$realtor-naver-blog-browser 파주 상지석동 창고 매매 23억, 연면적 180평, 층고 8.5m, 40피트 트레일러 진입 가능.
사진은 이 폴더 전부 써줘: /Users/나/Desktop/파주창고사진
```

사진 폴더를 주면 **기본으로 전부 싣습니다.** 완전히 같은 사진, 흔들린 사진, 매물과 관계없는 사진만 이유를 남기고 뺍니다. 지도 공유 링크(`fin.land.naver.com/map?...`)에는 매물번호가 없어서, 그 경우 상세 링크나 번호를 한 번 더 묻습니다.

**블로그 아이디**는 처음 한 번만 묻고 저장합니다. 내 블로그 주소 `blog.naver.com/` 뒤의 영문·숫자가 아이디입니다. 임시저장할 블로그를 정확히 고르기 위해 필요합니다.

처음에는 아래 내용을 한 번에 보내면 편합니다.

```text
매물번호: [번호]
내 블로그: https://blog.naver.com/[내 블로그 ID]
사무소명: [사무소명]
담당자명: [표시할 이름, 생략 가능]
상담 연락처: [공개 전화번호]
원하는 말투: 편안하고 전문적인 존댓말
```

번호가 없으면 이렇게 요청하세요.

```text
매물번호 없이 설명과 사진으로 진행할게요.
유형: [아파트 / 빌라 / 상가 / 사무실 / 공장 / 토지 등]
거래: [매매 / 전세 / 월세]
위치: [알고 있는 주소나 지역]
가격: [가격]
면적: [면적과 종류 — 전용 / 공급 / 대지 / 연면적 등]
입주시기: [알고 있는 조건]
특징: [확인된 장점과 제약]
사진: [첨부하거나 폴더 위치 안내]
```

모르는 칸에 추측을 적을 필요는 없습니다. Codex가 글에 필요한 내용을 묶어 질문합니다. 사진은 매물 설명과 함께 제공해 주세요.

## 3. 질문에 답하고 추천 전략을 확인하세요

예를 들어 면적이 어떤 기준인지, 주차대수가 서로 다르게 적혀 있는지 확인이 필요할 수 있습니다. 알고 있는 사실을 답하거나 아래처럼 요청할 수 있습니다.

```text
그 항목은 이번 글에서 제외해줘. 확인된 정보로 전략을 제안해줘.
```

유형이나 거래 방식처럼 글 전체를 결정하는 정보는 먼저 확정해야 합니다.

추천 이유나 고객 반응을 아직 설명하지 않았다면 “비슷한 매물보다 추천하는 점”, “고객이 좋아하거나 망설인 부분” 중 필요한 질문을 최대 2개 함께 묻습니다. 이미 충분히 설명했다면 다시 묻지 않습니다. 현장 질문은 건너뛰어도 되고, 답하지 않은 내용은 만들어 넣지 않습니다.

“우리 파주 창고 임대 고객은 차량 진입부터 물어요”처럼 사무소에서 반복되는 상담 경험은 기억했다는 짧은 안내와 함께 다음 조건에 맞는 매물 전략에도 반영합니다. “이 창고를 본 고객이 진입로를 좋아했다”는 해당 매물의 반응으로만 남깁니다. 고객 이름이나 연락처를 노하우로 보관하지 않습니다.

그다음 Codex가 **누구에게 소개할지, 어떤 장점을 앞에 둘지, 어떤 순서로 설명할지**를 표로 제안합니다.

마음에 들면:

```text
이 전략으로 진행해줘.
```

바꾸고 싶으면:

```text
이번에는 투자자보다 직접 사용할 고객을 중심으로 해줘.
가격과 공간 구성을 먼저 설명하는 방향으로 다시 제안해줘.
```

이 단계에서 방향을 정한 뒤 원고와 이미지를 제작합니다.

## 4. 원하는 말투를 알려주세요

기존 문체가 저장되어 있으면 우선 활용합니다. 처음이라면 블로그의 공개 매물 글을 참고합니다. 특별히 원하는 형식은 직접 말해 주세요.

```text
딱딱한 보고서 말투보다 고객에게 설명하듯 써줘.
짧은 문장으로 쓰고 한 문장 사이에 빈 줄 한 줄을 넣어줘.
전체 가운데 정렬을 유지해줘.
```

기존 글을 읽기 어려운 환경에서는 사용자가 설명한 말투와 기본 문체로 진행할 수 있습니다.

## 5. 네이버 로그인이 필요하면 직접 로그인하세요

Codex가 내장 브라우저의 네이버 화면을 안내합니다. 그 화면에서 본인 계정으로 직접 로그인하고, 끝나면 대화에 알려주세요.

```text
로그인했어. 이어서 진행해줘.
```

아이디·비밀번호·인증번호를 대화창에 보낼 필요는 없습니다. 실제 글쓰기 대상이 본인 블로그인지 확인하세요.

## 6. 임시저장과 검수가 끝날 때까지 기다리세요

Codex는 검증된 원고를 편집기에 넣고 사진·표·연락처를 확인합니다. 임시저장 후에는 **같은 제목과 저장 시각의 글을 다시 열어** 내용을 비교합니다.

완료 보고에서 아래 두 가지를 함께 보세요.

| 보고 항목 | 읽는 방법 |
|---|---|
| 저장 상태 `SAVED` | 저장 신호와 저장본 식별을 확인했습니다. |
| 완성도 `완료` | 같은 글을 재열람해 필요한 항목을 모두 대조했습니다. |

`보완 필요`나 `확인 불가`가 있으면 보고된 항목을 해결한 뒤 다시 검수하도록 요청하세요. 저장 상태만 보고 공개 발행하지 마세요.

## 7. 직접 읽고 발행 여부를 결정하세요

네이버 블로그 글쓰기 화면에서 임시저장 목록을 열고, 보고받은 제목과 저장 시각의 글을 선택하세요. 버튼의 이름이나 위치는 네이버 화면에 따라 달라질 수 있습니다.

매물 가격·면적·사진·사무소명·전화번호를 마지막으로 읽어보세요. 글을 공개하려면 최종 검토 후 사용자가 직접 발행합니다.

## 수정하거나 이어서 작업하기

**같은 임시저장 글의 말투 수정**

```text
방금 임시저장한 글을 조금 더 간결하게 바꿔줘.
같은 글에 반영하고 다시 열어 검수해줘.
```

**가격이나 매물 조건이 바뀐 경우**

```text
매매가가 [새 가격]으로 바뀌었어.
이 조건을 반영해 전략과 원고를 다시 확인해줘.
```

**중간에 작업이 멈춘 경우**

```text
지난 작업을 이어서 해줘.
원고 파일과 임시저장 목록부터 확인하고,
이미 저장된 글이 있으면 그 글에서 재개해줘.
```

**다음 매물 작성**

같은 사무소의 적용 가능한 상담 노하우도 함께 참고합니다. 이전 매물의 가격·면적·진입 조건을 새 매물에 가져오지는 않습니다.

```text
$realtor-naver-blog-browser
새 매물번호 [번호]야. 사무소 정보와 문체는 지난번과 같아.
추천 전략부터 보여줘.
```

**상담 노하우 수정 또는 잊기**

```text
앞으로 우리 파주 창고 임대 상담에서는 내부 배치부터 설명해줘.
지난번에 기억한 차량 진입 우선 항목은 잊어줘.
```

수정 의도가 명확하면 기존 항목을 대체하고, 무엇을 우선할지 모호하면 확인될 때까지 적용을 보류합니다. 기억이 추가되거나 바뀌었다는 이유만으로 이미 확정한 글 전략을 자동 변경하지 않습니다.
