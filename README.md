# Realtor Naver Blog

**매물 정보를 건네면, 내 말투에 맞는 네이버 블로그 글을 임시저장까지.**

공인중개사를 위한 Codex 스킬입니다. 스킬은 Codex가 반복 업무를 처리할 때 참고하는 작업 지침과 도구 묶음입니다. 매물의 장점을 누구에게 어떻게 설명할지 먼저 함께 정하고, 사진·조건표·상담 안내가 들어간 글을 만듭니다.

**처음이라면 아래 ① 설치 요청 → ② 첫 매물 요청 순서로 따라 하세요.** 터미널 명령을 직접 입력하지 않아도 Codex에 설치를 요청할 수 있습니다.

[처음부터 따라 하기](docs/first-post.md) · [막혔을 때 해결하기](docs/troubleshooting.md) · [직접 설치하기](docs/manual-install.md)

## 시작하기 전에 준비할 것

| 준비할 것 | 어디에 쓰나요? |
|---|---|
| Codex와 내장 브라우저 | 파일을 만들고 네이버 편집기에 글을 넣습니다. |
| 내 네이버 블로그 주소 | 글을 저장하고 기존 글의 말투를 참고합니다. |
| 매물번호 또는 매물 설명·사진 | 글의 근거가 됩니다. |
| 사무소명과 공개 상담 연락처 | 글 끝의 상담 안내와 배너에 사용합니다. |

아직 Codex를 설치하지 않았다면 [OpenAI 시작 안내](https://learn.chatgpt.com/docs/quickstart)를 먼저 확인하세요. 이 스킬은 파일 작업과 내장 브라우저를 사용할 수 있는 데스크톱 Codex 환경을 기준으로 합니다. Node.js 20 이상이 필요하며, 매물번호 수집용 부품과 이미지 제작 기능의 사용 가능 여부는 설치할 때 확인합니다.

## ① 처음 한 번: 설치 요청하기

Codex의 새 대화에 아래 문장을 **그대로 복사해서 보내세요.**

```text
$skill-installer
https://github.com/eziwork/realtor-naver-blog 저장소의
realtor-naver-blog 폴더를 스킬로 설치해줘.

Node.js 20 이상과 매물번호 수집에 필요한 부품을 확인하고,
내장 브라우저와 이미지 제작 기능을 사용할 수 있는지도 확인해줘.
기존 사무소 프로필과 블로그 문체 설정이 있으면 보존해줘.
설치가 끝나면 내가 다음에 입력할 문장을 알려줘.
```

설치 후 새 대화에서 `$realtor-naver-blog`를 입력해 보세요. 스킬이 보이지 않으면 Codex를 다시 시작한 뒤 확인하세요. 다른 GitHub 저장소에서 스킬을 설치하는 방법과 자동 감지는 [공식 스킬 안내](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)에서도 확인할 수 있습니다.

## ② 첫 매물: 빈칸만 채워 요청하기

`[대괄호]` 부분을 본인 정보로 바꿔 보내세요. 비밀번호나 인증번호는 적지 않습니다.

```text
$realtor-naver-blog

처음 사용합니다. 아래 매물로 네이버 블로그 글을 만들고 싶어요.

매물번호: [네이버 매물번호]
내 블로그: https://blog.naver.com/[내 블로그 ID]
사무소명: [글에 표시할 사무소명]
담당자명: [표시할 이름, 생략 가능]
상담 연락처: [공개 가능한 전화번호]

부족한 정보는 글을 쓰기 전에 질문해 주세요.
추천 전략을 먼저 보여주고, 제가 확정하면 글을 작성해
임시저장한 뒤 같은 글을 다시 열어 검수해 주세요.
```

매물번호를 모르면 매물 상세 링크를 넣거나, 알고 있는 가격·면적·위치·특징을 적고 사진을 첨부해도 됩니다. 사진 파일을 사용할 때는 파일을 첨부하거나 사진 폴더 위치를 알려주세요.

## 요청한 다음에는 무엇을 하나요?

```mermaid
flowchart LR
    A[매물 정보 전달] --> B[부족한 정보 질문]
    B --> C[추천 전략 확인]
    C --> D[글과 이미지 제작]
    D --> E[네이버 임시저장]
    E --> F[같은 글 재열람 검수]
```

| Codex가 하는 일 | 사용자가 할 일 |
|---|---|
| 확인된 정보와 필요한 질문을 정리합니다. | 아는 정보를 답합니다. 모르는 항목은 제외해 달라고 할 수 있습니다. |
| 누구에게 어떤 장점을 전할지 추천합니다. | 마음에 들면 **“이 전략으로 진행해줘”**라고 답합니다. |
| 내 말투로 원고·사진 배치·표·배너를 만듭니다. | 원하는 말투나 강조점이 있으면 알려줍니다. |
| 내장 브라우저로 네이버에 접속합니다. | 로그인이 필요하면 네이버 화면에서 직접 로그인합니다. |
| 임시저장한 글을 다시 열어 원본과 비교합니다. | 완성된 글을 읽고 최종 발행 여부를 결정합니다. |

글은 **임시저장 상태**로 남습니다. 공개 발행은 사용자가 최종 검토 후 직접 진행합니다.

## 어떤 글이 만들어지나요?

- 매물과 독자에게 맞는 제목과 도입
- 공간 설명 옆에 배치한 매물 사진
- 가격·면적·입주시기 등 확인된 조건을 정리한 표
- 썸네일과 사무소 상담 배너
- 문의하면 무엇을 안내받는지 설명하는 상담 문구와 연락처
- 위치가 정확히 확인된 경우 지도

기본은 편안한 존댓말과 짧은 문장입니다. 한 문장마다 문단을 나누고, 문장 사이에 빈 줄 한 줄을 두며, 본문·소제목·사진 설명·표·연락처를 가운데 정렬합니다. 직접 요청한 말투와 형식이 우선합니다.

기존 블로그의 공개 매물 글을 최대 5개 참고해 문체를 저장할 수 있습니다. 이전 글의 매물 정보나 방문 경험을 새 글의 사실로 가져오지는 않습니다.

## 믿고 확인할 수 있는 작업 원칙

**필요한 정보는 쓰기 전에 묻습니다.** 답이 없는 항목은 글에서 제외하며, 고객용 글에 “모른다”, “미확인”, “정보가 서로 다르다” 같은 수집 상태를 적지 않습니다. 확인된 중요한 제약은 사실대로 설명합니다.

**같은 글을 다시 열어 확인합니다.** 저장 버튼을 누른 것만으로 완성이라고 하지 않습니다. 제목·본문·사진 순서·표 내용·지도·연락처를 대조하고, 저장 상태와 완성도를 함께 보고합니다.

**작업이 끊겨도 이어서 합니다.** 원고와 사진은 로컬에 남습니다. 다시 시작할 때는 기존 임시저장 글을 먼저 찾아 중복 작성을 방지합니다.

검색어는 매물과 독자를 고려한 추천 후보입니다. 실시간 검색량이나 상위 노출·문의 증가를 보장하는 도구는 아닙니다.

## 두 번째 매물부터는 더 짧게

사무소와 블로그 정보가 저장되어 있으면 이렇게 시작할 수 있습니다.

```text
$realtor-naver-blog
매물번호 [새 매물번호]로 진행해줘.
사무소 정보와 문체는 지난번과 같아. 추천 전략부터 보여줘.
```

전화번호나 말투가 바뀌었을 때도 대화로 알려주면 됩니다. [수정·중단 후 재개 예시](docs/first-post.md#수정하거나-이어서-작업하기)를 참고하세요.
