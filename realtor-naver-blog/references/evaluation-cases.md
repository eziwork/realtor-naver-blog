# 검증 사례

자동 테스트는 데이터 계약·파일 관리·상태 전이를 검증한다. 타겟 추론의 타당성과 문장 의미는 아래 기준으로 Codex가 실제 생성 결과를 검토한다. 준비된 fixture가 다르게 렌더링된다는 테스트를 'AI의 마케팅 판단이 검증됐다'고 설명하지 않는다.

| 입력 사례 | 기대되는 타겟·검색·구성·CTA의 차이 | 만들면 안 되는 주장 |
|---|---|---|
| 강남 공급 31평 아파트, 방 3개 | 실거주 공간 비교 / 강남 아파트 매매 / 방 배치→비용 / 가구 배치·총 비용 안내 | 전용 31평, 확인되지 않은 학군·가격 |
| 대학가 1.5룸 빌라, 보증금 500만·월세 40만·책상 | 준비 비용 중심 / 가구 있는 대학가 빌라 / 준비 가구→월 비용 / 관리비 항목 확인 | 도보 5분, 관리비 포함 |
| 같은 빌라에 분리 작업실·넓은 거실 조건 | 주거·작업 분리 / 작업 공간 표현 / 공간 분리부터 / 가구 배치 상담 | 대학가라 무조건 학생 타겟 |
| 역 인근 1층 상가, 개별 출입구 | 소규모 운영자 / 역 인근 1층 상가 / 동선→설비 조건 / 예정 업종 확인 | 높은 유동 인구, 음식점 허가 가능 |
| 파주 200㎡ 창고, 층고 6m·5톤 진입 | 물류 운영 / 차량 진입 창고 / 진입→상하차→내부 / 차량 규격별 회차 확인 | 모든 대형 차량 가능, 층고만으로 적재 단수 |
| 같은 창고 유형, 20㎡·소형차 진입 | 소규모 재고 / 소형 창고 / 규모·재고 배치 우선 / 실제 운용 확인 | 이전 5톤 조건 재사용 |
| 제주 해안가 400㎡ 토지, 지목 전 | 현장 조건 비교 / 제주 해안가 토지 / 확인된 위치·지목 소개 / 방문 상담; 도로·용도는 사전 질문 후 미응답이면 원고 제외 | 영구 조망, 숙박업·건축 가능, '도로·용도 미확인'이라는 독자용 설명 |

함께 확인:
- 원고에 필요한 누락·충돌은 작성 전에 Codex 질문 도구로 사용자에게 묻는다. 전략 승인과 사실 확인을 혼동하지 않는다. 미응답이면 해당 정보와 '모른다·확인 필요·정보 충돌' 설명을 고객용 글에서 모두 제외하고 내부 기록에만 남긴다.
- 확정 전 prepare/begin 거부. 가격·타겟 변경 후 재확정. 문체만 바꾸면 확정 유지.
- 스타일 재사용, 첫 분석 1~5개, 본문 0개 기본 전환, 표본 부족 표시, 사용자 요청 없는 저장 스타일 교체 거부.
- 현재 프로필과 다른 배너, 변조된 이미지/HTML, 출처 없는 수치·단위가 전송되지 않는다.
- 저장 후 같은 글 재열람. 실패·로그인 만료·저장 불명은 원고 보존+목록 확인 후 재시도.
- 실제 브라우저 시험과 모의 장애 시험을 구분해 검증 보고서에 기록한다.
- 말투 수정 요청은 과거 저장 문체보다 우선한다. 확인된 내용을 친숙하고 직접적으로 설명하며 출처·등록·관찰 같은 작업 용어를 독자용 문장에 반복하지 않는다. 미확인 정보는 쉬운 주의 문장으로 대체하지 않고 사전 질문 또는 원고 제외로 처리한다.
- 본문 한 문장당 한 블록, 가운데 정렬, 문장 사이 빈 줄 한 줄. 소제목·표 안의 글·사진 설명·CTA·연락처도 가운데 정렬한다. 로컬 HTML과 실제 저장본의 배치를 각각 확인한다.
