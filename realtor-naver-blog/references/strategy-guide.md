# 매물 → 이용 목적 → 검색 질문 → 상담 가치

지역/유형만 보고 고객을 단정하지 않는다. 이용 목적, 필요한 공간, 예산 구조, 이동/진입, 준비 기간, 불확실성 중 **주어진 조건으로 설명 가능한 우선순위**를 잡는다. 타겟은 근거를 가진 마케팅 가설이며 사실 데이터와 분리한다.

1. 확인된 조건과 모르는 조건을 나눈다. 원고에 필요한 누락·충돌은 작성 전에 Codex 질문 도구로 스킬 사용자에게 한 번에 묻는다. 가격/면적 충돌은 원문을 함께 제시한다. 미응답 항목은 글에서 제외하고 모른다는 설명도 넣지 않는다. 유형·거래처럼 글의 성립에 필요한 조건이 불명확하면 답을 기다린다.
2. 이용 목적 후보를 내부적으로 비교해 설명력이 높은 하나를 추천한다. 나이·가족 형태를 사실처럼 단정하지 않고 생활/사업 목적 중심으로 표현한다.
3. 검색 질문을 한 문장으로 만든다. '어떤 위치의 어떤 공간을 어떤 조건으로 찾는가?'
4. 중심 표현 1개와 관련 표현 2~4개를 **추천 후보**로 제시한다. 검색량이나 경쟁 강도를 추정하지 않는다. 지명·시설·규모를 근거 없이 추가하지 않는다.
5. 확인된 강점으로 후킹하고 망설임을 해소할 질문 순으로 문단을 만든다. 문단마다 근거와 사진을 연결한다.
6. 상담에서 안내/확인할 구체적인 내용을 CTA로 제안한다. 희소성·수익 보장·과장 표현을 쓰지 않는다.

| 유형 | 타겟과 설명 순서를 바꾸는 확인 항목 |
|---|---|
| 아파트 | 전용/공급 면적 구분, 방/욕실, 총 비용, 출퇴근 조건, 입주 시점, 관리비·주차 |
| 빌라·주택 | 분리 공간, 층/엘리베이터, 관리 항목, 가구 배치, 비용, 진입·주차 |
| 오피스텔 | 주거/업무 이용의 확인 범위, 분리 구조, 관리비 포함 항목, 옵션·주차 |
| 상가 | 층/출입·노출, 전용 면적, 전력·배수·배기, 임대/권리 조건, 요청 업종 확인 |
| 사무실 | 인원 배치·회의실, 출입/주차, 냉난방·관리비, 업무 시작 일정 |
| 창고·공장 | 차량 진입·회차, 층고·하중, 면적, 전력·설비, 상하차, 용도와 사용 조건 |
| 토지 | 위치·지목·용도지역, 도로 접면/권리, 경사·설비, 요청 활용의 확인 사항 |

조합별 예시를 공식처럼 적용하지 않는다. 대학가 1.5룸도 비용이 낮고 기본 가구가 있으면 비용·생활 준비부터, 분리 작업실과 넓은 면적이 확인되면 주거/작업 분리부터 설명한다. 대학 인근만으로 도보 시간을 만들지 않는다.

창고도 대형 차량 진입·회차가 확인되면 물류 흐름부터, 소형차만 가능하고 작은 면적이면 소규모 재고 운영부터 설명한다. 층고만으로 적재 단수나 장비 사용 가능을 확정하지 않는다.

제주 해안가 토지는 사진에 바다가 보여도 영구 조망·건축·숙박업 가능을 주장하지 않는다. 활용 가능성을 원고에 쓰려면 작성 전에 사용자에게 확인하고, 미응답이면 확인된 위치와 보이는 공간만 소개한다.

타겟·후킹·주요 문단 수정은 전략 갱신 후 재확인한다. 말투만 바꾸면 strategy.json은 유지한다.
