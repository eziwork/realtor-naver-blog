# v0.3 검증 기록

검증일: 2026-10-09. 배포 대상은 eziwork/realtor-naver-blog이며 스킬 호출명은 $realtor-naver-blog입니다.

자동 테스트 39개와 핵심 작업 규칙 검사, 스킬 형식 검증을 모두 통과했습니다.

현장 질문과 사무소 상담 노하우 기능을 기존 v0.2에 추가했습니다. 첫 사용자 안내, 수집기, 문체·가운데 정렬 규칙, 전략 확정 및 내장 브라우저 전송 절차를 유지합니다.

자동 테스트는 다음을 확인합니다.

- 현장 설명이 충분하면 질문 생략, 부족하면 중복 없이 최대 2개·한 묶음
- 답변·건너뛰기·미응답 상태와 매물 사실·중개사 평가·고객 반응의 분리
- 반복 적용 의도가 명확한 사용자 경험 저장, AI 추론·개별 경험 분류 및 연락처가 들어간 기억 입력 차단
- 유형·지역·거래 범위 조회, 중복 방지, 명시적 수정, 모호한 충돌 보류, 잊기와 자동 부활 방지
- 노하우의 참조 스냅샷 검증 및 새 기억 저장 뒤 기존 전략 확정 유지
- 연속 두 매물에서 상담 우선순위만 재사용하고 이전 면적·층고·차량 진입 조건은 섞이지 않음
- 기존 사무소 YAML·블로그 문체 보존, 프로필 간 분리, 선택 필드 없는 작업 호환
- 기존 전략 확정·문체·사실 참조·원고·이미지·전송 상태와 저장 후 재열람 판정

실행: 저장소 루트에서 npm test, node realtor-naver-blog/scripts/check-core.mjs 및 skill-creator의 quick_validate.py.

노하우 테스트는 임시 사무소 폴더에서 수행합니다. 실제 사무소 기록에는 예시를 저장하지 않습니다. 자연어의 의미·일반화 여부·이름 익명화·타겟의 적절성은 Codex가 원문을 보고 검토해야 합니다.

이번 변경에서 실제 네이버 글을 새로 저장하거나 공개 발행하지 않았습니다. 자동 테스트의 브라우저 장애·재열람 판정은 상태 전이 모의 검증이며, 실제 편집기 동작이나 검색 유입 성과의 검증과 구분합니다.
