# 막혔을 때 해결하기

[첫 화면으로 돌아가기](../README.md) · [첫 글 따라 하기](first-post.md)

오류가 나면 Codex 대화에서 **어느 단계까지 진행했는지와 오류 문구**를 알려주세요. 비밀번호나 인증번호는 보내지 않습니다.

## 설치와 시작

| 상황 | 이렇게 해보세요 |
|---|---|
| `$realtor-naver-blog`가 보이지 않아요. | 새 대화를 열어 확인하고, 그래도 없으면 Codex를 다시 시작하세요. 설치한 폴더 안에 `SKILL.md`가 있는지 Codex에 확인을 요청하세요. |
| 설치 경로가 이미 있다고 해요. | 기존 설치를 지우지 말고 “사무소 정보와 문체를 보존하고 업데이트해줘”라고 요청하세요. |
| Node.js 또는 npm을 찾을 수 없어요. | “Node.js 20 이상 설치 여부와 실행 경로를 확인해줘”라고 요청하세요. |
| Playwright나 Chromium이 없다고 해요. | “설치된 realtor-naver-blog 스킬 폴더에서 npm ci를 실행해줘”라고 요청하세요. 다운로드가 막혔다면 오류와 네트워크 상태를 확인합니다. |
| 내장 브라우저나 이미지 제작 기능을 쓸 수 없어요. | 현재 환경에서 가능한 기능을 먼저 확인하세요. 원고는 보관하고, 부족한 기능이나 이미지를 준비한 뒤 이어갈 수 있습니다. |

## 매물 정보와 사진

| 상황 | 이렇게 해보세요 |
|---|---|
| 매물을 찾지 못해요. | 번호를 다시 확인하세요. 삭제되거나 접근이 제한된 매물은 설명과 사진을 직접 제공해 진행할 수 있습니다. |
| 지도 링크만 줬더니 번호를 물어요. | 지도 공유 링크 대신 매물 상세 화면의 매물번호나 상세 링크를 전달하세요. |
| 등록 사진 중 일부가 빠졌어요. | 수집 결과에서 누락 목록을 확인하고 해당 사진을 보완하거나, 확보한 사진만 사용하겠다고 명시하세요. |
| 질문받은 정보를 저도 몰라요. | “그 항목은 이번 글에서 제외해줘”라고 답하세요. 유형·거래 방식처럼 필수 정보는 먼저 확인해야 합니다. |
| 표에 면적이 잘못 들어갔어요. | 정확한 값과 기준을 함께 알려주세요. 예: “195㎡는 전용면적이 아니라 연면적이야.” |
| 지도가 들어가지 않았어요. | 정확한 장소를 특정할 수 있어야 지도에 넣습니다. 주소를 보완하거나 이번 글에서는 생략할 수 있습니다. |

## 로그인과 저장

| 상황 | 이렇게 해보세요 |
|---|---|
| 네이버 로그인이 필요하다고 해요. | Codex가 안내한 내장 브라우저 화면에서 직접 로그인한 뒤 “로그인했어”라고 알려주세요. |
| 엉뚱한 블로그가 열려요. | 작업을 멈추고 내 블로그 주소와 로그인 계정을 확인하세요. 올바른 주소를 Codex에 전달하세요. |
| 저장 중에 작업이 끊겼어요. | “기존 원고와 임시저장 목록부터 확인하고 같은 글에서 이어가줘”라고 요청하세요. |
| `SAVED`인데 `확인 불가`예요. | 저장은 확인했지만 재열람 검수가 끝나지 않았다는 뜻입니다. 같은 글을 다시 열어 검수하도록 요청하세요. |
| `UNVERIFIED`라고 해요. | 저장 여부가 불명확한 상태입니다. 새 글을 만들기 전에 임시저장 목록에서 제목과 저장 시각을 확인해야 합니다. |
| 사진·표·전화 링크가 일부 달라요. | 어떤 항목이 다른지 알려주고 같은 임시저장 글에 보완하도록 요청하세요. |

## 문체와 사무소 정보

**문체가 마음에 들지 않으면 구체적으로 알려주세요.**

```text
이모지는 빼고, 쉬운 존댓말과 짧은 문장으로 바꿔줘.
이 요청을 다음 글에도 적용하도록 문체 설정에 반영해줘.
```

**상담 전화가 바뀌었다면 배너와 링크까지 함께 갱신하세요.**

```text
공개 상담 전화가 [새 번호]로 바뀌었어.
사무소 프로필과 본문 연락처, 전화 링크, 상담 배너에 반영해줘.
```

사무소 정보와 저장 문체는 스킬 설치 폴더와 별도로 관리합니다. 기본 위치는 `~/.codex/naver-realtor-blog/`입니다. 이 폴더나 로그인 데이터는 공개 GitHub 저장소에 올리지 않습니다.
